# Personal Portfolio Website

## Overview
A responsive personal portfolio website developed for **Software Development 1 (CSE-2340)**.  
The site presents academic background, projects, achievements, and technical skills in a clean, modern layout.

Built using **HTML5, CSS3, and vanilla JavaScript**, the website follows modern UI/UX practices and is fully responsive across desktop, tablet, and mobile devices.

## Features
- Responsive single-page design  
- Smooth scrolling and interactive navigation  
- Project showcase and education timeline  
- Achievements, blog, and publications sections  
- Contact form integrated with Google Sheets  
- Cross-browser compatibility  

## Technologies
- **HTML5** – Structure and semantics  
- **CSS3** – Styling, Flexbox, Grid, responsiveness  
- **JavaScript (ES6+)** – Interactivity and validation  
- **Google Apps Script** – Contact form backend  
- **GitHub Pages** – Deployment  

## SDLC
- Requirement Analysis  
- UI/UX Design  
- Implementation  
- Testing  
- Deployment & Maintenance
